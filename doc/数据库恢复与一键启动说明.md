# 数据库恢复与一键启动说明

本文档适用于当前仓库对应的 **教学资源管理系统** 本机开发环境恢复。

---

## 1. 数据库恢复

### 1）默认恢复脚本

仓库已提供：

```bat
bin\restore-db.bat
```

### 2）默认恢复信息

- MySQL Host：`127.0.0.1`
- MySQL Port：`3306`
- 数据库名：`ry-vue`
- 用户名：`root`
- 密码：`czp123..`
- 默认 SQL 文件：
  - `backup\2026-03-24\database\ry-vue-full-20260324.sql`

### 3）直接执行

在项目根目录打开命令行后执行：

```bat
bin\restore-db.bat
```

### 4）指定数据库名或 SQL 文件

```bat
bin\restore-db.bat ry-vue backup\2026-03-24\database\ry-vue-full-20260324.sql
```

> 第一个参数是数据库名，第二个参数是 SQL 文件路径。

## 2. 一键启动

### 1）启动脚本

```bat
bin\start-all.bat
```

该脚本会按顺序执行：

1. 启动 Redis
2. 启动后端
3. 启动前端

### 2）单独启动

#### 启动 Redis

```bat
bin\start-redis.bat
```

#### 启动后端

```bat
bin\start-backend.bat
```

#### 启动前端

```bat
bin\start-frontend.bat
```

### 3）关闭常用进程

```bat
bin\stop-all.bat
```

## 4. 启动逻辑说明

### 后端

- 如果已有：
  - `ruoyi-admin\target\ruoyi-admin.jar`
- 则直接运行 jar

否则：

- 自动调用 Maven 进行打包
- 打包完成后再启动 jar

### 前端

- 如果已有 `node_modules`
  - 直接执行 `npm run dev`
- 如果没有 `node_modules`
  - 自动先执行 `npm install`
  - 再执行 `npm run dev`

### Redis

- 优先检测 `127.0.0.1:6379`
- 若已运行则不重复启动

## 6. 常见问题 / 避坑

### 1）MySQL 导入失败

重点检查：

- MySQL 服务是否已启动
- root 密码是否仍为 `czp123..`
- `bin\env.cmd` 中的连接信息是否正确

### 2）后端无法启动

重点检查：

- Redis 是否已启动
- 8080 端口是否被占用
- `application-druid.yml` 中数据库配置是否与本机一致

### 3）前端无法启动

重点检查：

- Node.js / npm 是否安装
- `ruoyi-ui\node_modules` 是否完整
- 80 端口是否被其他程序占用

### 4）换机器后脚本找不到命令

统一去这里修改：

```bat
bin\env.cmd
```

## 7. 推荐恢复顺序

建议按下面顺序恢复环境：

1. 安装 MySQL
2. 安装 Redis
3. 安装 Java
4. 安装 Node.js / npm
5. 安装 Maven
6. 执行数据库恢复：
   - `bin\restore-db.bat`
7. 执行一键启动：
   - `bin\start-all.bat`
