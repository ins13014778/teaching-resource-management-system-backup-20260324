# 数据库恢复与一键启动说明

本文档适用于当前仓库对应的 **教学资源管理系统** 本地开发环境恢复。

## 1. 数据库恢复

### 1.1 推荐恢复脚本

```bat
bin\restore-db.bat
```

### 1.2 默认恢复信息

- MySQL Host：`127.0.0.1`
- MySQL Port：`3306`
- 数据库名：`ry-vue`
- 用户名：`root`
- 密码：`czp123..`
- 默认 SQL 文件：`backup\2026-03-24\database\ry-vue-full-20260324.sql`

### 1.3 直接执行

```bat
cd /d D:\RuoYi-Vue-master
bin\restore-db.bat
```

### 1.4 指定数据库名或 SQL 文件

```bat
cd /d D:\RuoYi-Vue-master
bin\restore-db.bat ry-vue backup\2026-03-24\database\ry-vue-full-20260324.sql
```

> 第一个参数是数据库名，第二个参数是 SQL 文件路径。

## 2. 一键启动

### 2.1 启动脚本

```bat
bin\start-all.bat
```

启动顺序如下：

1. Redis
2. 后端
3. 前端

### 2.2 单独启动

#### 启动 Redis

```bat
bin\start-redis.bat
```

#### 启动后端

```bat
bin\start-backend.bat
```

#### 启动前端

```bat
bin\start-frontend.bat
```

### 2.3 关闭当前项目相关进程

```bat
bin\stop-all.bat
```

## 4. 启动逻辑说明

### 4.1 Redis

- 先检测 `127.0.0.1:6379` 是否已响应 `PONG`
- 若未启动，则在 Redis 安装目录中执行：`redis-server.exe redis.conf`

### 4.2 后端

- 优先检查是否已有 `ruoyi-admin.jar` 对应 Java 进程运行
- 再检查 `8080` 是否被其它程序占用
- 若存在 `ruoyi-admin\target\ruoyi-admin.jar`，直接运行 jar
- 若不存在 jar，则自动调用 Maven 打包后再启动

### 4.3 前端

- 若存在 `ruoyi-ui\node_modules`，直接 `npm run dev`
- 若不存在 `node_modules`，先 `npm install` 再 `npm run dev`

## 6. 常见问题 / 避坑

### 6.1 MySQL 导入失败

重点检查：

- MySQL 服务是否已启动
- root 密码是否仍为 `czp123..`
- `bin\env.cmd` 中的连接信息是否正确

### 6.2 后端无法启动

重点检查：

- Redis 是否已启动
- 8080 端口是否被其他程序占用
- `application-druid.yml` 中的数据库配置是否与本机一致

### 6.3 前端无法启动

重点检查：

- Node.js / npm 是否安装
- `ruoyi-ui\node_modules` 是否完整
- 80 端口是否被其他程序占用

### 6.4 PowerShell 手动导库乱码

推荐直接执行：

```powershell
Set-Location 'D:\RuoYi-Vue-master'
cmd /c bin\restore-db.bat
```

不要直接把历史 SQL 备份在 PowerShell 中用重定向导入。

## 7. 推荐恢复顺序

1. 安装 MySQL
2. 安装 Redis
3. 安装 Java
4. 安装 Node.js / npm
5. 安装 Maven
6. 执行 `bin\restore-db.bat`
7. 执行 `bin\start-all.bat`
